# Identifying Network Hubs with the Partial-Correlation Graphical LASSO

This repository contains code to reproduce all experiments, figures, and tables from the paper **"Identifying Network Hubs with the Partial-Correlation Graphical LASSO"** by Bogdan, Chojecki, Hejný, Kołodziejek, and Wallin.

**Paper**: https://arxiv.org/abs/2601.16945  
**Method**: [pcglassoFast](https://github.com/PrzeChoj/pcglassoFast) R package

---

## Installation

Install all required dependencies:

```r
# Standard CRAN packages
install.packages(c(
  "remotes", "Matrix", "glasso", "glmnet", "igraph",
  "ggplot2", "dplyr", "readr", "patchwork", "ggpatchwork",
  "yaml", "pbapply", "microbenchmark", "parallel", "MASS"
))

# Our method (pcglassoFast) from GitHub
remotes::install_github("PrzeChoj/pcglassoFast")

# Carter's PCGLASSO algorithm (for comparison) from GitHub
remotes::install_github("JackStorrorCarter/PCGLASSO")

# SPACE: archived version (v0.1-1.1 is required for reproducibility)
install.packages(
  "https://cran.r-project.org/src/contrib/Archive/space/space_0.1-1.1.tar.gz",
  repos = NULL,
  type = "source"
)
```

## Reproducing Results

Run any script below to generate the corresponding paper figures and tables. Output files are saved to `outputs/`.

### Section 3.3: Irrepresentability Condition

**Figure 1** — Irrepresentability condition on hub-structured graphs.

```r
source("experiments/Section_3_3.R")
```

**Runtime**: ~2 minutes
**Output**: `outputs/Figure_1.png`

---

### Section 4.1: Gene Expression Analysis

**Figures 2–5** — Network estimation on Sanger gene expression dataset using BIC model selection.

```r
source("experiments/Section_4_1.R")
```

**Runtime**: ~2 minutes  
**Output**: `outputs/Figure_2.png` through `outputs/Figure_5.png`

---

### Section 4.2: Prostate Cancer RNA-seq Analysis

**Figures 6–11** — GLASSO, Cor-GLASSO, and PC-GLASSO comparison on prostate cancer RNA-seq data. Includes EBIC path comparison, hub diagnostics, and collinearity analysis.

```r
source("experiments/Section_4_2/analysis.R")
```

**Runtime**: ~5 minutes  
**Outputs**:
- `outputs/Section_4_2_ebic_comparison.png` (EBIC paths)
- `outputs/Section_4_2_adjacency_matrices.png` (Network structures)
- `outputs/Section_4_2_hub_diagnostics_alpha1.png` (Hub metric α¹)
- `outputs/Section_4_2_hub_diagnostics_alpha2.png` (Hub metric α²)
- `outputs/Section_4_2_degree_distribution.png` (Network degrees D)
- `outputs/Section_4_2_collinearity_analysis.png` (Condition numbers)
- Additional appendix figures (Appendix B.1)

---

### Section 4.3: Simulation Study

**Tables 1–4** — Hub-structured and non-hub covariance simulations comparing PC-GLASSO variants against GLASSO, Cor-GLASSO, SPACE, and HubCorGLASSO.

```r
source("experiments/Section_4_3/run_simulation.R")
```

**Runtime**: HPC cluster (100 cores): ~1.5 hours

**Outputs**:
- `results/` directory with `.rds` files for each method and sample size
- Tables 1–4 and diagnostic plots generated by `make_tables_figures.R`

---

### Appendix A: Timing Benchmarks

Computational time scaling with problem dimension $p$.

See `experiments/Appendix_A/` for a suite of calibrated benchmarking scripts.

**Scripts** (run in order):
1. `0_parameters.R` — Set up benchmark parameters
2. `1_instances_construction.R` — Generate test instances
3. `2_functions_simulations.R` — Define benchmark functions
4. `3_run_simulations.R` — Execute timing experiments
5. `4_functions_plot.R` — Set up plotting utilities
6. `5_compute_best_values.R` — Compute reference times
7. `6_plot.R` — Generate individual plots
8. `7_combine_plots.R` — Combine into final figures

**Runtime**: HPC cluster (100 cores): ~5 hours

---

### Appendix D: Diagonal Optimization Convergence

Comparison of Newton versus gradient descent for diagonal element optimization.

```r
source("experiments/Appendix_D/diag_newton.R")
```

**Runtime**: ~5 minutes
**Output**: Convergence plot comparing optimization algorithms
